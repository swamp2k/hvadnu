# Hvad nu?

Mobile-first decision support for navigating a long-running family-law case without losing source traceability.

> Status: foundation bootstrap. No production deployment, no live user data, and no Cloudflare or Anthropic resources are configured yet.

The project is intentionally designed so that AI-generated interpretations never become the source of truth. Original evidence, source provenance, effective dates, and explicit uncertainty remain first-class data.
